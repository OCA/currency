Now you can choose the 'Frankfurter' service when configuring a currency
rates providers.

1.  Go to *Invoicing \> Configuration \> Currency Rates Providers*.
2.  Create a new 'Currency Rates Providers' or edit an existing one and
    you will see 'Frankfurter' among the available 'Source Services' to
    choose.
3.  If you choose 'Frankfurter' as a 'Source Service', the exchange rates
    will be updated from that provider.
