This module adds `AllRatesToday <https://allratestoday.com/>`_ as a
currency rates provider. Instead of a market feed, it loads the table
that one named publisher printed for the day: a central bank or tax
authority such as the ECB, the Reserve Bank of India, HMRC, the Central
Bank of Kenya or the Bank of Canada. Over 120 publishers are covered,
each by its short code (``ecb``, ``rbi``, ``hmrc``, ``cbk``, ...).

That is the rate many tax, customs and statutory accounting rules
require ("the rate published by the central bank on the invoice date"),
which the other providers cannot supply for most countries.

Publishers quote in different directions (the ECB prints foreign
currency per 1 EUR, the RBI prints INR per 1 foreign unit). The module
normalises every table to the publisher's home currency and rebases it
to the company currency, so the direction stored in Odoo is always the
one ``currency_rate_update`` expects.

The latest table is fetched keylessly. Past dates (the update wizard
with a date range) need an AllRatesToday API key on a paid plan.

Configuration
=============

1. Go to *Invoicing > Configuration > Currency Rates Providers*.
2. Create a provider and choose *AllRatesToday (official central-bank
   rates)* as the *Source Service*.
3. Set the *Publisher code*: the short code of the central bank or tax
   authority whose table your company must use. The list is at
   https://allratestoday.com/central-bank-rates-api/institutions/
   (default ``ecb``).
4. Optionally paste an *API key* (free at
   https://allratestoday.com/register). It is only needed to load past
   dates, which require a paid plan.
5. Optionally pin a *Rate type* (``buy``, ``sell``, ``middle``,
   ``reference``, ...) when the publisher prints several series for the
   same pair.
6. Pick the currencies to update. The list offered is the set of
   currencies in the publisher's latest table.

Usage
=====

The scheduled action of ``currency_rate_update`` loads the latest table
automatically. Use *Update Rates Now* on the provider to load it on
demand, or give the wizard a date range to load the tables of past days
(one request per day; a day without a publication takes the newest
table printed before it, as the publisher's own rules require). Without
an API key a date range yields the latest table only.

The company currency must appear in the publisher's table, otherwise
the update is refused with a message naming the publisher and the date.
